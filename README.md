# ProjectOps 1차 화면

이 작업은 `CMP-33` 이슈의 1차 범위를 만족하는 정적 웹 화면입니다.

## 구현 범위

- 프로젝트 목록 화면
- 프로젝트 등록/수정 화면
- 프로젝트 상세 화면
- 진행사항 업데이트 등록/조회 화면
- 고객사 / 사내 구분

## 지원 필드

### 프로젝트 필드

- 프로젝트명
- 유형: `고객사`, `사내`
- 고객사명
- 담당자/PM
- 참여 인력
- 시작일/종료일
- 계획 맨먼스
- 계약 맨먼스
- 사용 맨먼스
- 예상 맨먼스
- 진행률
- 상태: `계획`, `진행중`, `위험`, `완료`, `보류`
- 리스크/메모

### 진행사항 업데이트 필드

- 작성일
- 작성자
- 이번 업데이트 내용
- 다음 계획
- 이슈/리스크
- 진척률 변경

## 실행/배포 방법

### 1) 로컬 실행

```bash
cd /paperclip/repos/projectops
python3 -m http.server 8090
```

브라우저에서 `http://127.0.0.1:8090` 또는 환경의 노출 URL로 접속합니다.

### 2) 코드 배포(현재 워크스페이스 기준)

```bash
cd /paperclip/repos/projectops/.paperclip/worktrees/CMP-33-projectops-1
git pull
```

현재 화면은 정적 자원만 사용하므로 웹 서버가 정적 파일을 읽을 수 있는 위치에 `index.html`, `styles.css`, `app.js`를 배포하면 됩니다.

## 저장소 구조

- `index.html`: 화면 레이아웃 및 템플릿
- `styles.css`: 화면 스타일
- `app.js`: localStorage 기반 상태 관리/CRUD/진행 업데이트 로직
- `README.md`: 실행 가이드 및 범위

## 주의

- 1차 구현이라 별도의 인증, 권한 제어, 외부 연동은 제외했습니다.
- 데이터는 브라우저 `localStorage`에 `projectops.projects.v1` 키로 저장됩니다.
